## 当前结论

M6 的 RDP helper、桌面 companion 工作区、relay client/protocol/service、schema 4 profile 与配置 UI 已实现。自动化覆盖 named-pipe 正确/错误 token、帧和参数校验、密码脱敏、direct-first、真实 TCP/TLS fallback、target mapping、token、并发 quota、opaque forwarding 和 schema 3 原位升级。

本机没有随应用分发的 `wfreerdp.exe`，因此没有执行真实 RDP 连接、窗口/DPI、证书变化或 helper 崩溃后的人工恢复。QUIC client/server 实现可编译，但本机 UDP loopback 测试在收到初始数据后未完成握手并由 client timeout；它不是通过证据。真实 QUIC/TLS、协议降级、总字节/带宽/时长的对抗边界和长时资源测试仍是退出门槛，因此 M6 不能标记 `Complete`。
