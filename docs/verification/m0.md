## 验证结果

| 范围 | 证据 | 结果 |
| --- | --- | --- |
| Rust/Tauri 骨架 | 全工作区 check、clippy、test；前端 production build | 通过 |
| SSH/SFTP | 进程内真实 `russh` server/client，密码认证、host key 回调、PTY echo 与独立 SFTP channel | 通过 |
| Tauri channel | Release 下交替发送 10,000 个终端/监控事件，每个 1 KiB | Rust 侧分发 9.474 ms，无事件丢失 |
| SQLite | 专用 actor、WAL、迁移 checksum、online backup、损坏主库 fail-closed 与备份恢复 | 通过 |
| 密钥与记录加密 | Windows Credential Manager 写入/读取/删除，HKDF + XChaCha20-Poly1305，AAD 替换和篡改失败 | 通过 |
| RDP helper IPC | Windows named pipe、本机限制、stdin 单次令牌、正确/错误令牌与帧上限 | 通过 |
| 许可证 | Cargo 606 个包与 npm 81 个包自动审查，人工复核高风险候选 | 通过 |

Release 基准脚本为 [`scripts/run-m0-benchmarks.ps1`](../../scripts/run-m0-benchmarks.ps1)。SSH 首次 Release 编译在本次记录中为 56.528 秒，测试本身约 10 ms；该编译时间不是产品连接延迟。前端的 `measureIpcChannel` 使用真实 Tauri channel 计算 WebView 收齐事件的端到端时间，当前 headless 脚本只冻结 Rust 侧自动化基线，不把未自动采集的 WebView 数字列为结论。

## 已冻结边界

- 桌面端保持模块化单体和单向 crate 依赖。
- SSH 逻辑会话使用有界交互/批量双 lane，SFTP 可使用独立 channel。
- SQLite 只能经专用 actor 访问；敏感 payload 使用记录级认证加密。
- RDP 引擎位于独立 helper，首选 FreeRDP，主进程只依赖版本化 IPC。
- Tauri WebView 只获得最小 capability，不接收仓库主密钥或通用系统能力。

## 限制与后续门槛

M0 是技术验证，不代表连接 CRUD、可用终端、SFTP、同步或 RDP 产品功能完成。冷启动、长期内存、10 终端加 2 传输和 OpenSSH SFTP 对比需要在对应功能可用后的 M2、M3、M7 验收中测量。
